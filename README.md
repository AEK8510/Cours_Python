# Python Programming Course

Teaching and practice material for an introductory-to-intermediate Python programming course.

The repository contains progressive exercises and examples covering core Python syntax, file handling, NumPy, Matplotlib, object-oriented programming, Pandas, linear algebra, and small applied projects.

## Repository structure

### `S1/` — Python fundamentals and scientific basics

Examples include:

- file input/output;
- operating-system and command-line utilities;
- NumPy arrays and numerical operations;
- data visualization with Matplotlib;
- small programming exercises and a final project.

### `S2/` — Object-oriented and numerical Python

Examples include:

- classes, inheritance, and static methods;
- matrix operations;
- singular value decomposition (SVD);
- Pandas data manipulation;
- simple prediction exercises;
- additional applied Python examples.

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib

## Purpose

This repository is primarily intended for teaching, demonstrations, and hands-on exercises. It reflects a progressive approach to Python programming, from fundamental concepts to numerical and data-oriented applications.
